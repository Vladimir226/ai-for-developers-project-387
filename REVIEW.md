# Критерии ревью — «Календарь звонков»

Независимый авторевьюер получает этот файл в запросе воркфлоу
[`autoreview`](.github/workflows/autoreview.yml) вместе с контекстом PR:
диффом, описанием, обсуждениями по ссылкам и статусами CI. Критерии ниже —
постоянная часть; конкретный PR добавляет свою спецификацию и согласование.

## Формат замечания

Замечание содержит: **файл, строку, условия ошибки и её последствие** — что
сломается при этих условиях и для кого. Замечания форматирования — дело
линтера, его вывод в ревью не дублируется. Если подтверждённых дефектов нет,
ревьюер сообщает об этом прямо и не придумывает замечания ради объёма.

## Объём изменения

- Изменение сверяется со спецификацией и согласованием человека по ссылкам
  из описания PR. Выход за согласованный объём — замечание о scope. Ссылки
  недоступны или согласования нет — ревью отмечает этот пробел.
- `src/generated/` руками не правится: изменения API начинаются в
  `contract/` (ADR-010) и генерируются `npm run contract:gen`; расхождение
  ловит drift-check в CI.

## Критерии домена

1. **Занятость слота.** Занятый слот недоступен для повторной записи:
   брони — полуинтервалы `[startsAt, endsAt)`, наложение с любой активной
   бронью (включая другие типы событий) отклоняется 409; примыкание
   интервалов допустимо. Отмена брони освобождает время для всех типов.
2. **Доступные слоты.** Слот бронируем, только если он целиком в будущем,
   начинается на сетке рабочих часов и длится ровно длительность типа
   события; старт — не раньше чем через 30 минут после текущего момента
   (минимальный запас до звонка, ADR-0014): слот и выдаётся, и бронируется
   по одному правилу, старт ровно на границе допустим. Сервер —
   единственный источник истины (ADR-004): UI слоты не вычисляет; слишком
   близкий будущий старт — 409 `SLOT_TOO_SOON`, проверяется после
   `SLOT_IN_PAST`.
3. **Время.** Хранение и передача — UTC, отображение — в `APP_TZ`
   (ADR-009). Смешение зон в одном слое — дефект.
4. **UI и данные.** UI ходит через SDK и `router.refresh()` (ADR-004);
   каждое исключение фиксируется ADR (ссылка-скачивание `.ics` — ADR-0013).
   Публичные страницы не выполняют мутаций.
5. **Ошибки.** Единый JSON-конверт ошибок; `text/calendar` — единственное
   не-JSON-исключение (аддендум ADR-0005). Неизвестный id — 404 в конверте,
   невалидное тело — 422, конфликт слота — 409.
6. **ICS (RFC 5545).** `DTSTART`/`DTEND` в UTC; строки свёрнуты до 75
   октет; значения TEXT экранированы; `UID` стабилен между повторными
   скачиваниями; несуществующая и отменённая бронь — 404.
7. **Публичная поверхность.** Страница «Предстоящие записи» read-only
   (ADR-0012); новые публичные данные или мутации без ADR не появляются.
8. **Тесты.** Основной и негативный сценарии спецификации покрыты тестами
   внешнего поведения (ответы API, экран); соседний сценарий не сломан —
   существующие e2e зелёные. Тест проверяет поведение, а не внутреннюю
   структуру модулей.
9. **Коммиты.** Conventional Commits; коммит реализации ссылается на
   закрываемый тикет.

## Чего ревьюер не делает

- Не правит код и не перезапускает CI: замечания адресованы человеку,
  правки выполняет агент разработки по команде `/oc` (README, «Агент
  в GitHub»). Комментарий авторевью исправления не запускает.
- Не повторяет замечания, уже разобранные в предыдущих ревью этого PR:
  повторный запуск проверяет новые правки и затронутое поведение.
